# NeuroHabitos

Aplicacion movil-first pensada para iPhone para crear, seguir y analizar habitos conectados entre si.

## Incluye

- Panel diario con habitos de hoy
- Alta y edicion de habitos
- Dependencias entre habitos
- Analisis diario tipo IA basado en reglas locales
- Modulo de neurociencia aplicado
- Persistencia en `localStorage`

## Abrir

Abre `index.html` directamente en el navegador.

## Estructura

- `index.html`: estructura y vistas
- `styles.css`: diseño movil-first
- `app.js`: estado, renderizado y motor de analisis
- `brief-codex-vs.md`: briefing largo para futuras iteraciones

## Nota

Esta version no necesita backend. Toda la informacion se guarda en el navegador del dispositivo.
